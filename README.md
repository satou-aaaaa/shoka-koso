# 消化酵素あて（shoka-koso）

消化酵素や消化液の説明（だ液の酵素・胃液の酵素・肝臓でつくられる液 など）を読んで、アミラーゼ・ペプシン・トリプシン・リパーゼ・胆汁を当てる1日5問の学習ゲーム。正解したら「何を消化する？」（デンプン・タンパク質・脂肪）も選ぶ。中学2年理科「動物の体のつくりと働き」。

遊ぶ: <https://satou-aaaaa.github.io/shoka-koso/>

- 中身は大阪府教育委員会の中学2年理科プリント、大阪府教育センターのワークシート、兵庫県立高校の授業資料、広島県の資料、長寿科学振興財団の健康長寿ネットで確かめたことだけです。
- 胆汁は消化酵素ではなく消化液です。病気や薬のことは扱いません。このゲームは教科書の代わりではありません。くわしくは教科書で確かめてください。
